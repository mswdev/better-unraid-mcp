**Goal:** Ship release 0.0.13 — a tier-2 SSH `flash_backup` tool (timestamped tar of `/boot/config`, or the whole flash with `full: true`, into `/mnt/user/<share>/flash-backups/`, verified with `tar -tzf`, optional `keep` pruning) — and record that VM snapshot revert/delete stay descoped after live validation.

**Architecture:** One new tool file `src/tools/backup/flash-backup.ts` (new `backup/` directory) following the `vm_snapshot_create` pattern: `sshUnavailableError` → input validation → `requireRiskAcknowledgementInteractive` → a share-existence probe → one `tar` command → a verification command → optional prune command, each through the injectable `ShellExecutor`, with a progress heartbeat (`startProgressHeartbeat`) because a full-flash archive of 2.6 GB can take minutes. Archive names embed a client-side timestamp from an injectable clock so the tool knows the exact path it wrote.

**Tech Stack:** unchanged (no new dependencies).

### Task 1: `flash_backup` tool

**Files:**
- Create: `src/tools/backup/flash-backup.ts`, `src/tools/backup/flash-backup.test.ts`
- Modify: `src/tools/registry.ts` (import + `{ isMutating: true, register: (server, { shell }) => registerFlashBackup(server, shell) }` next to the ZFS entries), `src/tools/registry.test.ts` (tool count / read-only listing expectations if asserted)

**Interfaces:**
- `export interface FlashBackupArgs { response_format: ResponseFormat; share: string; full?: boolean; keep?: number; confirm?: boolean; acknowledge_risk?: boolean }`
- `export interface FlashBackupDeps { shell: ShellExecutor | null; channel?: ElicitationChannel | null; now?: () => Date }`
- `export function createFlashBackupHandler(deps: FlashBackupDeps)` → `(args: FlashBackupArgs, extra?: unknown) => Promise<CallToolResult>`
- `export function archiveNameFor(scope: "config" | "full", now: Date): string` → `flash-backup-<scope>-YYYYMMDD-HHMMSS.tar.gz` (UTC).
- `export function registerFlashBackup(server: McpServer, shell: ShellExecutor | null): void`
- Constants: `SHARE_NAME_PATTERN = /^[A-Za-z0-9._-]+$/`, `USER_SHARES_ROOT = "/mnt/user"`, `BACKUP_SUBDIR = "flash-backups"`, `FLASH_ROOT = "/boot"`, `CONFIG_SUBDIR = "config"`, `PROBE_TIMEOUT_MS = 10_000`, `ARCHIVE_TIMEOUT_MS = 900_000` (15 min, full flash), `VERIFY_TIMEOUT_MS = 300_000`, `PRUNE_TIMEOUT_MS = 30_000`, `TAR_WARNING_EXIT_CODE = 1` (GNU tar: "some files differ"/"file changed as we read it").

Command shapes (all arguments through `quoteForShell`):
1. probe: `test -d '/mnt/user/<share>'` → exit ≠ 0 → `toolError("Share \"<share>\" does not exist under /mnt/user — see share_list. No changes were made.")`
2. archive (config): `mkdir -p '<dir>' && tar -czf '<dir>/<name>' -C '/boot' 'config'`; (full): `... -C '/boot' .`
3. verify: `tar -tzf '<file>' | wc -l && stat -c %s '<file>'` → parse two lines: entry count, bytes.
4. prune (only when `keep` set): `ls -1t '<dir>'/flash-backup-*.tar.gz | tail -n +<keep+1>` → for each listed path (must start with `<dir>/flash-backup-`) `rm -f` in ONE follow-up command joining quoted paths; report removed names. (Two commands so the tool can report exactly what it deleted.)

Result copy (concise): `Flash backup written: <file> (<N> entries, <human size>). Verified with tar -tzf. ⚠ The archive contains your Unraid license key, API keys, passwords, and network config — keep it on the array or encrypt it before copying it anywhere. [Pruned K older archive(s): …]`. Detailed payload `{ path, scope, entries, bytes, pruned: string[], warnings: string | null }`.
