# 0.0.12 "DX quick wins" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship release 0.0.12 — a `doctor` CLI mode, a schema/API version-skew check, local dry-run validation for the raw GraphQL tools, honest batch copy for `notification_archive`, and (discovered during planning) a refreshed vendored schema that retires `array_disk_action remove` and switches container restart to the API's native mutation.

**Architecture:** The vendored SDL gets a sidecar `schema/schema-version.json` written by a new `scripts/update-schema.mjs` (replaces the bare curl) recording the upstream `api/package.json` version at fetch time; `src/resources/schema-sdl.ts` gains `loadSchemaVersion()` next to `loadSchemaSdl()`. `connection_doctor` receives that version through `DoctorDeps` and emits a `schema` check comparing major.minor with the server's reported API version. A new `src/cli/doctor.ts` renders the doctor checks to stdout for `npx better-unraid-mcp doctor` (argv dispatch in `src/index.ts` before transport startup, exit 1 on any `fail`). `src/tools/graphql/_shared.ts` builds a graphql-js schema lazily from the SDL and validates parsed documents before they are sent; both raw tools gain `dry_run`.

**Tech Stack:** unchanged. graphql-js `buildSchema`/`validate` (already a dependency; the vendored SDL builds in ~20 ms).

**Spec:** `docs/superpowers/specs/2026-09-15-roadmap-2-design.md` §6 Phase 1.

- Copy rule: tools never claim results the API does not report.

## Facts established during planning (2026-09-17)

- Vendored SDL dates from 2026-05-31; upstream `main` is API **4.37.4** (= Deepwater's live version) and differs: `Mutation.array.removeDiskFromArray` was **retired** upstream (unraid/api#2068, 2026-08-29), `Mutation.docker.restart(id)` was **added** (#2022), `ArrayStartInput`-style `decryptionPassword`/`decryptionKeyfile` fields were added to array start, and two type blocks moved. After refresh, `array_disk_action remove` no longer compiles → retire it (D23); `docker_container_action restart` can use the native mutation (D24).
- `Query.upsDevices` etc. unchanged. Notification batch mutations (`archiveNotifications`/`unarchiveNotifications`) return only a `NotificationOverview`; per-id failures are swallowed upstream (`batchProcess` → `Promise.allSettled`, results discarded) — verified in the notification API notes; the tool copy must say so.

```ts
const VERSION_CANDIDATES = ["../schema/schema-version.json", "../../schema/schema-version.json"];

/** Reads the first candidate path that exists, or null. */
function readFirst(candidates: string[], readFile: SchemaFileReader): string | null {
  for (const candidate of candidates) {
    try {
      return readFile(new URL(candidate, import.meta.url));
    } catch {
      // Try the next candidate location.
    }
  }
  return null;
}

/**
 * The upstream unraid/api version the vendored SDL was fetched from, recorded
 * by `npm run schema:update` in schema/schema-version.json.
 *
 * @param readFile - File reader (injectable for tests).
 * @returns The version string (e.g. "4.37.4"), or null when not recorded.
 */
export function loadSchemaVersion(readFile: SchemaFileReader = defaultReader): string | null {
  const raw = readFirst(VERSION_CANDIDATES, readFile);
  if (raw === null) return null;
  try {
    const parsed: unknown = JSON.parse(raw);
    const version = isRecord(parsed) ? parsed.apiVersion : undefined;
    return typeof version === "string" ? version : null;
  } catch {
    return null;
  }
}
```

- [ ] **Step 4: Write `scripts/update-schema.mjs`** (Node ≥ 20, no deps):

```js
// Refreshes the vendored Unraid API schema and records the upstream version it came from.
import { writeFileSync } from "node:fs";
const RAW = "https://raw.githubusercontent.com/unraid/api/main/api";
const HEADER = "# Vendored from https://github.com/unraid/api (api/generated-schema.graphql).\n# DO NOT EDIT BY HAND. Refresh with `npm run schema:update`.\n";
const [sdl, pkg] = await Promise.all([
  fetch(`${RAW}/generated-schema.graphql`).then((r) => { if (!r.ok) throw new Error(`SDL fetch failed: ${r.status}`); return r.text(); }),
  fetch(`${RAW}/package.json`).then((r) => { if (!r.ok) throw new Error(`package.json fetch failed: ${r.status}`); return r.json(); }),
]);
writeFileSync("schema/unraid.graphql", HEADER + sdl);
writeFileSync("schema/schema-version.json", `${JSON.stringify({ apiVersion: pkg.version, source: "https://github.com/unraid/api", fetchedAt: new Date().toISOString() }, null, 2)}\n`);
console.log(`schema/unraid.graphql refreshed from unraid/api ${pkg.version}`);
```
