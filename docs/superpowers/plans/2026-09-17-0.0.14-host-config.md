# 0.0.14 "Coverage: host configuration (SSH)" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship release 0.0.14 — seven SSH-backed host-configuration tools the GraphQL API cannot offer: `service_list` / `service_action`, `unassigned_list` / `unassigned_action`, `share_create` / `share_edit` / `share_delete` — each validated live (read-only) on Deepwater and against `unraid/webgui` source, each refusing rather than guessing when its substrate is missing.

**Architecture:** Three new tool directories (`src/tools/service/`, `src/tools/unassigned/`, plus three files added to `src/tools/share/`), all following the `flash_backup` pattern: `sshUnavailableError` → argument validation → gate (`requireRiskAcknowledgementInteractive` for writes) → substrate probe → command(s) through the injectable `ShellExecutor` → **read-back verification** → honest report. Share writes go through emhttpd exactly as the web UI does (`emcmd` with the ShareEdit/SecuritySMB form fields) and are verified by re-reading `/boot/config/shares/<name>.cfg`. Unassigned Devices actions go through the UD plugin's `rc.unassigned mount|umount <partition>`; without the plugin the tool refuses with guidance.

**Tech Stack:** unchanged.

**Spec:** `docs/superpowers/specs/2026-09-15-roadmap-2-design.md` §6 Phase 3 and §5 live-validation rule.

## Global Constraints

- Branch `feature/0.0.14-host-config` off `develop`; draft PR into `develop`; gate before every commit; `npm run format` after `npm version`.
- `.claude/rules/` hard limits; ≤ 10 source files per directory (`src/tools/share` → 4, `src/tools/service` → 2 + `_shared.ts`, `src/tools/unassigned` → 2 + `_shared.ts`).
- Every write tool: tier-2 gate, `No changes were made.` in every refusal, read-back verification, copy never claims more than verified.
- **Refuse rather than guess**: unknown service → refuse; UD plugin missing → refuse; share cfg unreadable after write → report "unverified", never "done".
- Share names: `^[A-Za-z0-9._-]{1,40}$`, not starting with `.`, not reserved (`reservedNames` from `/var/local/emhttp/var.ini`, plus pool and disk names from `disks.ini`) — case-insensitive.

### Task 1: `service_list` + `service_action` (`src/tools/service/`)

**Files:** Create `src/tools/service/_shared.ts`, `service-list.ts`, `service-list.test.ts`, `service-action.ts`, `service-action.test.ts`; modify `src/tools/registry.ts` (+2 entries), `registry.test.ts` (count).

**Interfaces (`_shared.ts`):**
```ts
export const SERVICES = { samba: "rc.samba", nfs: "rc.nfsd", sshd: "rc.sshd", docker: "rc.docker", libvirt: "rc.libvirt", tailscale: "rc.tailscale" } as const;
export type ServiceName = keyof typeof SERVICES;
export const RC_DIR = "/etc/rc.d";
export function rcScript(name: ServiceName): string;                 // "/etc/rc.d/rc.samba"
export type ServiceState = "running" | "stopped" | "not_installed" | "unknown";
export function parseStatusOutput(stdout: string): ServiceState;      // /currently running/ → running; /not running/ → stopped; else unknown
export const SERVICE_TIMEOUT_MS = 60_000;
```
**`service_list`** (read-only): one command `for s in rc.samba …; do if [ -x /etc/rc.d/$s ]; then echo "$s: $(/etc/rc.d/$s status 2>&1 | head -1)"; else echo "$s: NOT_INSTALLED"; fi; done` → map to `{ name, script, state, detail }`; concise: `samba: running`, …
**`service_action`** (tier-2): `action: restart | start | stop`; `stop` requires `allow_stop: true` (samba/nfs cut off shares); `stop`/`start` of `docker` and `libvirt` are **refused outright** ("use array_action / the web UI") — `restart` allowed for all. Flow: validate → gate → probe `[ -x /etc/rc.d/rc.X ]` (refuse "not installed") → run `/etc/rc.d/rc.X <verb>` → read-back `status` → report `state after: running|stopped` and `verified` = matches expectation.

Tests (each with `sequencedShell`): list parses running/stopped/not-installed lines; action refuses without flags (0 calls); `stop` without `allow_stop` refused; `stop docker` refused even with `allow_stop`; unknown service rejected by zod-free guard (call with `"nginx" as never`); `restart samba` runs `/etc/rc.d/rc.samba restart` then `status`, verified true when "currently running"; verified false + honest text when read-back says not running; not-installed probe refusal (1 call).

### Task 2: `unassigned_list` + `unassigned_action` (`src/tools/unassigned/`)

**Files:** Create `src/tools/unassigned/_shared.ts`, `unassigned-list.ts(+test)`, `unassigned-action.ts(+test)`; registry +2.

**Interfaces (`_shared.ts`):**
```ts
export const DISKS_INI = "/var/local/emhttp/disks.ini";
export const LSBLK_COMMAND = "lsblk -J -o NAME,KNAME,TYPE,SIZE,FSTYPE,MOUNTPOINT,LABEL,MODEL,SERIAL,TRAN";
export const UD_SCRIPT = "/usr/local/sbin/rc.unassigned";

export interface UnassignedDisk { device: string; model: string | null; serial: string | null; size: string; transport: string | null; partitions: Array<{ device: string; fstype: string | null; mountpoint: string | null; label: string | null; size: string }> }
export function selectUnassigned(lsblkJson: string, assigned: Set<string>): UnassignedDisk[]; // type=="disk", kname ∉ assigned, skip loop/zram

```
**`unassigned_list`** (read-only): two commands (`cat disks.ini`, lsblk) → table `device model size fs mountpoint`; empty → "No unassigned disks (every block device belongs to the array, a pool, or the flash)."
**`unassigned_action`** (tier-2): `action: mount | unmount`, `device` (partition path, validated by `PARTITION_PATTERN`); probe `[ -x /usr/local/sbin/rc.unassigned ]` else refuse with "install the Unassigned Devices plugin (Community Applications); raw mount is deliberately not offered"; refuse if the device's parent disk is assigned (re-uses `parseAssignedDevices` on a fresh `cat disks.ini`); run `rc.unassigned mount|umount '/dev/sdX1'`; read-back `lsblk -J -o KNAME,MOUNTPOINT '/dev/sdX1'` → `verified` (mounted ⇔ mountpoint non-null).

Tests: parseAssignedDevices from a disks.ini fixture; selectUnassigned drops array/pool/flash/loop and keeps a spare with partitions; list renders; action refusals (flags, bad device, assigned device, plugin missing) with call counts; mount success verified; mount unverified (mountpoint still null) reports `verified: false`; unmount verified.

### Task 3: `share_create` / `share_edit` / `share_delete` (`src/tools/share/`)

**Files:** Create `src/tools/share/_shared.ts` (share cfg parsing, emcmd builder, name validation, read-back), `share-create.ts(+test)`, `share-edit.ts(+test)`, `share-delete.ts(+test)`; registry +3.

**Interfaces (`_shared.ts`):**
```ts
export const SHARE_CFG_DIR = "/boot/config/shares";
export const SHARES_ROOT = "/mnt/user";
export const EMCMD = "/usr/local/sbin/emcmd";
export const SHARE_NAME_PATTERN = /^[A-Za-z0-9_][A-Za-z0-9._-]{0,39}$/;
export const RESERVED_SHARE_NAMES = ["flash", "boot", "disks", "disk", "user", "cache", "parity", "remotes", "addons", "rootshare", "user0"];
export type CacheMode = "no" | "yes" | "only" | "prefer";
export type Allocator = "highwater" | "fillup" | "mostfree";
export type SmbExport = "-" | "e" | "eh";
export type SmbSecurity = "public" | "secure" | "private";
export interface ShareSettings { comment?: string; allocator?: Allocator; useCache?: CacheMode; cachePool?: string; smbExport?: SmbExport; smbSecurity?: SmbSecurity }
export function parseShareCfg(text: string): Record<string, string>;                 // key="value" lines
export function buildEditQuery(name: string, nameOrig: string, current: Record<string,string>, changes: ShareSettings, command: "Add Share" | "Apply" | "Delete"): string; // URL-encoded (encodeURIComponent) form body: every ShareEdit field, changed values overriding current cfg values, blanks for unset
export function buildSmbQuery(name: string, current: Record<string,string>, changes: ShareSettings): string | null; // null when no SMB field changes; includes changeShareSecurity=Apply
export function emcmdCommand(query: string): string;                                 // `/usr/local/sbin/emcmd '<query>'` via quoteForShell
export function isReservedName(name: string, extra: string[]): boolean;             // case-insensitive
```
Flow shared by create/edit: validate name → gate → read `cat /boot/config/shares/<name>.cfg` (create: must NOT exist → else refuse "exists; use share_edit"; edit: must exist) → read `/var/local/emhttp/disks.ini` names + `var.ini reservedNames` for reserved/pool-name checks → validate `cachePool` against pool names present in disks.ini (`type="Cache"` sections) → run `emcmd` edit query (exit ≠ 0 → toolError with emhttpd's text) → run SMB query if needed → read-back `cat cfg` → compare each requested key → `verified` true/false with the diff listed.
**`share_delete`**: name validation → gate → cfg must exist → emptiness check `find '/mnt/user/<name>' -mindepth 1 -print -quit` (non-empty → refuse: "share still contains data at /mnt/user/<name> on <disks from shares.ini?>; delete only removes the CONFIG — move or delete the files first") → `emcmd 'shareName=X&shareNameOrig=X&cmdEditShare=Delete'` → read-back: cfg absent ⇒ verified.

Tests: parse/build helpers (URL encoding of spaces/ampersands, defaults preserved, `cmdEditShare` value); name validation (reserved, pool name, leading dot, 41 chars, case-insensitive duplicates); create refuses existing; edit refuses missing; unknown pool refused before emcmd; emcmd failure surfaces text and reports nothing verified; read-back mismatch → `verified: false`; delete refuses non-empty (call count), deletes and verifies absence.
